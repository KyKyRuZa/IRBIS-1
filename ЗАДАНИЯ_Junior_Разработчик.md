# 📋 Задачи для junior-разработчика по проекту IRBIS

> [!info] Общая суть

## 📦 Задание 1: Групповая выдача СИЗ

### Что нужно сделать

Сейчас при выдаче можно выбрать только **ОДНОГО** сотрудника. А по ТЗ нужно уметь:

1. Выбрать объект
2. Выбрать позицию (например, «мыло»)
3. Система сама создаёт записи выдачи для **ВСЕХ** активных сотрудников этого объекта

> [!tip] Подсказка
> У тебя уже есть функция `createIssueRecord` в модели — используй её в цикле для каждого сотрудника.

### Пошаговая инструкция

#### 1. Сервер — новый endpoint

Создай функцию `batchIssue(req, res)` в `server/src/controllers/issueRecordController.js`:

```javascript
// Что принимать из req.body:
// - site_id (обязательно)
// - item_type_id (обязательно)
// - quantity (по умолчанию 1)
// - certificate_id (необязательно)

// Что делать:
// 1. Найти всех сотрудников с status='active' и нужным site_id
// 2. Для каждого сотрудника создать запись в issue_records
// 3. Вернуть массив созданных записей
```

#### 2. Сервер — маршрут

Добавь в `server/src/routes/issueRecordRoutes.js`:

```javascript
POST /api/issues/batch → вызывает batchIssue
```

#### 3. Клиент — интерфейс

Открой `client/src/pages/IssueForm.jsx` и добавь:

- [ ] Новую секцию «Групповая выдача»
- [ ] Выпадающий список «Объект» (загрузка через `/api/sites`)
- [ ] При выборе объекта — загрузка сотрудников этого объекта
- [ ] Выпадающий список «Наименование СИЗ»
- [ ] Поле «Количество»
- [ ] Кнопку «Выдать всем»
- [ ] POST на `/api/issues/batch` с `site_id`, `item_type_id`, `quantity`
- [ ] После успешной выдачи — обновить список

## ⏰ Задание 2: Ручная корректировка срока носки

### Что нужно сделать

Сейчас срок годности (`expiry_date`) считается автоматически: дата выдачи + `default_wear_time_months`. Но по ТЗ нужно давать возможность указать **другой** срок для конкретной выдачи.

### Пошаговая инструкция

#### 1. Клиент — форма выдачи

В `client/src/pages/IssueForm.jsx`:

- [ ] Добавь checkbox «Указать индивидуальный срок годности»
- [ ] Когда отмечен — показывай поле ввода даты «Срок годности до»
- [ ] При отправке — если checkbox отмечен, отправляй `expiry_date` вместе с остальными данными

#### 2. Сервер — обработка

В `server/src/controllers/issueRecordController.js` в функции `issueItem`:

- [ ] Получай `expiry_date` из `req.body`
- [ ] Если передан — используй его вместо автоматического расчёта
- [ ] Если не передан — считай как раньше (старая логика)

#### 3. Сервер — модель

В `server/src/models/issueRecordModel.js` в `createIssueRecord`:

- [ ] Проверь, что `expiry_date` есть в INSERT (уже должно быть)

> [!note] Важно
> Дата приходит из формы как строка `YYYY-MM-DD` — это подходит для PostgreSQL.
