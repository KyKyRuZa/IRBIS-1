# 🚀 Полная инструкция по установке проекта IRBIS

> [!info] Что это за проект?
> **IRBIS** — система учёта спецодежды, СИЗ и расходных материалов сотрудников АЗС.
> 
> **Стек:**
> - **Backend:** Node.js + Express + PostgreSQL
> - **Frontend:** React + Vite
> - **Документы:** генерация Word (docx, docxtemplater) и Excel
> - **Архивы:** archiver (ZIP)
>
> Ниже — пошаговая установка всего окружения с нуля.

---

## 📋 Что нужно установить (чеклист)

| # | Программа | Версия | Зачем |
|---|-----------|--------|-------|
| 1 | Node.js | 18+ (рекомендуется 24.x) | Для запуска бэкенда и фронтенда |
| 2 | npm | идёт с Node.js | Установка зависимостей |
| 3 | PostgreSQL | 17 | База данных |
| 4 | Git | любая | Для работы с репозиторием |
| 5 | VS Code | последняя | Редактор кода |

## 🖥️ Шаг 1: Установка Node.js и npm

### macOS

```bash
# Установка через Homebrew (если Homebrew нет: https://brew.sh)
brew install node@24

# Проверка версий:
node --version    # должно быть v24.x.x или v18+
npm --version     # должно быть 10+
```

### Windows

**Способ A — через официальный установщик:**
1. Скачай https://nodejs.org/en/download/
2. Выбери **LTS версию** (рекомендуется 24.x)
3. Запусти установщик, нажимай «Next»
4. После установки открой PowerShell и проверь:

```powershell
node --version
npm --version
```

**Способ B — через winget:**
```powershell
winget install OpenJS.NodeJS.LTS
```

### Linux (Ubuntu/Debian)

```bash
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt-get install -y nodejs
node --version
npm --version
```

### Linux (Fedora/RHEL)

```bash
sudo dnf install nodejs npm
node --version
npm --version
```

> [!note] Про npm
> npm идёт вместе с Node.js автоматически. Если вдруг его нет:
> ```bash
> npm install -g npm@latest
> ```

## 🗄️ Шаг 2: Установка PostgreSQL 17

### macOS

```bash
# Установка через Homebrew
brew install postgresql@17

# Запуск PostgreSQL
brew services start postgresql@17

# Создание базы данных
psql -U postgres -c "CREATE DATABASE irbis;"
```

### Windows

1. Скачай установщик: https://www.postgresql.org/download/windows/
2. Выбери **PostgreSQL 17**
3. Установи, запомни пароль для пользователя `postgres` (по умолчанию `postgres`)
4. После установки открой **pgAdmin** или командную строку:

```powershell
# Создание базы данных через psql (вставляй пароль, который задал при установке)
psql -U postgres -c "CREATE DATABASE irbis;"
```

### Ubuntu/Debian Linux

```bash
# Добавление репозитория PostgreSQL
sudo sh -c 'echo "deb https://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/postgresql.gpg > /dev/null
sudo apt-get update
sudo apt-get install -y postgresql-17

# Запуск
sudo systemctl start postgresql
sudo systemctl enable postgresql

# Создание базы данных
sudo -u postgres psql -c "CREATE DATABASE irbis;"
```

### Fedora/RHEL Linux

```bash
sudo dnf install postgresql17-server
sudo postgresql-17 initdb
sudo systemctl start postgresql-17
sudo -u postgres psql -c "CREATE DATABASE irbis;"
```

## ⚙️ Шаг 6: Настройка переменных окружения

Бэкенд использует файл `.env` для подключения к базе данных. Он уже есть в проекте.

**Если нужно изменить** (например, пароль от PostgreSQL):

```bash
cd server
nano .env    # macOS/Linux
# или notepad .env  # Windows
```

**Структура `.env`:**
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=irbis
DB_USER=postgres
DB_PASSWORD=postgres
PORT=5000
```

> [!note] Важно
> Поля `DB_USER` и `DB_PASSWORD` должны совпадать с данными твоего PostgreSQL.
> Если при установке PostgreSQL задал другой пароль — измени `DB_PASSWORD`.

## 🗃️ Шаг 7: Инициализация базы данных

Сервер сам создаёт таблицы при первом запуске. Нужно только создать пустую базу:

```bash
# macOS/Linux
psql -U postgres -c "CREATE DATABASE irbis;"

# Windows (в PowerShell, если PostgreSQL в PATH)
psql -U postgres -c "CREATE DATABASE irbis;"

# Или через pgAdmin: правый клик на Databases → Create → имя: irbis
```

> [!warning] Если база уже существует
> ```bash
> psql -U postgres -c "DROP DATABASE irbis;"
> psql -U postgres -c "CREATE DATABASE irbis;"
> ```

## 🐛 Частые проблемы и решения

### ❌ `npm install` зависает или выдает ошибку

```bash
# Очисти кэш и попробуй снова
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### ❌ `EACCES` ошибка при установке пакетов (macOS/Linux)

```bash
# Используй nvm (Node Version Manager)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc    # или ~/.zshrc
nvm install 24
nvm use 24
```

### ❌ PostgreSQL не запускается / connection refused

```bash
# macOS
brew services restart postgresql@17

# Linux
sudo systemctl restart postgresql

# Проверь статус
sudo systemctl status postgresql
```

### ❌ База данных `irbis` не создаётся (already exists)

```bash
# Удали и создай заново
psql -U postgres -c "DROP DATABASE irbis;"
psql -U postgres -c "CREATE DATABASE irbis;"
```

### ❌ `psql: command not found`

```bash
# macOS
brew install postgresql@17
brew link --force postgresql@17

# Windows — добавь в PATH:
# C:\Program Files\PostgreSQL\17\bin

# Linux
sudo apt-get install postgresql-client
```

### ❌ Порт 5000 или 5173 занят

```bash
# macOS/Linux — найди процесс
lsof -i :5000
kill -9 <PID>

# Windows
netstat -ano | findstr :5000
taskkill /PID <PID> /F
```

### ❌ Frontend не может подключиться к API (CORS / proxy ошибки)

Убедись, что:
1. Бэкенд запущен на порту 5000
2. В `vite.config.js` настроен proxy:
   ```javascript
   proxy: {
     '/api': {
       target: 'http://localhost:5000',
       changeOrigin: true,
     },
   },
   ```
3. В `client/src/index.css` или конфиге нет запрета CORS

## 🆘 Если ничего не работает

1. **Перезагрузи терминал** — иногда переменные окружения не применяются
2. **Проверь версии:**
   ```bash
   node --version
   npm --version
   psql --version
   ```
3. **Убедись, что база существует:**
   ```bash
   psql -U postgres -l
   ```
4. **Посмотри логи сервера** — там обычно понятно, что сломалось
5. **Переустанови зависимости:**
   ```bash
   cd server && rm -rf node_modules && npm install
   cd ../client && rm -rf node_modules && npm install
   ```
